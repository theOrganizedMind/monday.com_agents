# Monday.com Customer Config Board Layout: 

This document describes the columns, types, and possible values for the Monday.com boards used by the `dispatch_agent`.
The **Customer Config** board should have the following structure for full compatibility.

---

## A/R Board Columns

| Column Name      | Type                | Example Values / Notes                                                                 |
|------------------|---------------------|----------------------------------------------------------------------------------------|
| **Company**      | Text                | Customer Name (e.g., "Example Company")                                            
| **AR Exempt**    | Checkbox            | Check if Company is AR Exempt                                          
| **PO Required**  | Checkbox            | Check if Company requires a Job or PO Number                                                              
| **Prepaid**      | Checkbox            | Check if Company is required to prepay for services
