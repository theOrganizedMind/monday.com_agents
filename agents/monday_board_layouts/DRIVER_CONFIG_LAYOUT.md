# Monday.com Drivers Config Board Layout: 

This document describes the columns, types, and possible values for the Monday.com boards used by the `dispatch_agent`.
The **Drivers Config** board should have the following structure for full compatibility.

---

## A/R Board Columns

| Column Name      | Type                | Example Values / Notes                                                                 |
|------------------|---------------------|----------------------------------------------------------------------------------------|
| **Driver**       | Text                | Driver First and Last Name (e.g., "Jane Doe")                                            
| **Board ID**     | Text                | Driver Board ID Number                                       
| **Active**       | Checkbox            | Check if Driver is an active employee
