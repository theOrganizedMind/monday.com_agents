# Monday.com A/R Board Layout: 

This document describes the columns, types, and possible values for the Monday.com boards.
The **A/R** board should have the following structure for full compatibility.

---

## A/R Board Columns

| Column Name      | Type                | Example Values / Notes                                                                 |
|------------------|---------------------|----------------------------------------------------------------------------------------|
| **Customer**     | Text                | Customer Name (e.g., "Example Company")                                            
| **Current**      | Number              | Current A/R amount by customer                                          
| **1-30**         | Number              | 1-30 A/R amount by customer                                                               
| **31-60**        | Number              | 31-60 A/R amount by customer                                 
| **61-90**        | Number              | 61-90 A/R amount by customer
| **91 and over**  | Number              | 91 and over A/R amount by customer
| **Total**        | Formula             | Total A/R amount by customer
